# CITIMART Daily Operations — Runtime Logs Directory

> **Centralized Structured Logging, Correlation Tracing & Audit Trails**  
> Output directory for rotated log files generated by the FastAPI backend, middleware, and background workers.

---

## 📂 Log Files Overview

| Log File | Purpose | Retention & Rotation |
|:---|:---|:---|
| **`app.log`** | General application runtime events, service initialization, and debug traces | Rotated at 10MB, up to 5 backups |
| **`access.log`** | HTTP request/response metrics (Method, Path, Status Code, Latency in ms) | Rotated at 20MB, up to 10 backups |
| **`audit.log`** | Security audit trails (User Logins, Password Changes, Target Updates, Directives) | Immutable, long-term retention |
| **`error.log`** | Unhandled exceptions and error stack traces | Rotated at 10MB, up to 5 backups |
| **`worker.log`** | Background jobs, BullMQ tasks, and midnight auto-finalization settlement logs | Rotated at 10MB, up to 5 backups |

---

## 🔍 Correlation ID Tracing

Every request passing through the backend is stamped with an `X-Correlation-ID` header. This ID is propagated across all log entries to enable end-to-end trace correlation:

```json
{
  "timestamp": "2026-11-20T13:30:00.123Z",
  "level": "INFO",
  "correlation_id": "c7a8b9f1-3d2e-4b5a-9f8e-123456789abc",
  "store_id": "NM",
  "user": "new_market",
  "endpoint": "/api/daily/stores/NM/summary",
  "latency_ms": 4.2,
  "status_code": 200
}
```
